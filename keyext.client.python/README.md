# key-rpcclient-python

Python client for the KeY RPC server.

## Installation

From the project root, create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the package in editable mode with development dependencies:

```bash
pip install -e ".[dev]"
```

## Running tests

```bash
pytest
```

## Formatting

```bash
black .
```
